CHRISSI'S ARENA

chrissi's Arena is a minimalist, retro-styled auto-fire roguelite where movement is the only input that matters. Your weapon aims and fires by itself. Collect gold, buy upgrades between waves, survive as long as you can.

VSync uses your monitor's native refresh timing directly and disables the manual framerate cap above. Music and sound effects are synthesized live with the Web Audio API (oscillators and noise bursts shaped into notes), so nothing needs to load. If the game runs choppy, check that hardware/GPU acceleration is enabled in your browser's settings.

PHASE 2 OF 5
✓
Phase 1: Prototype
A single HTML file, built to prove the core idea worked: auto-fire, movement-only controls, a shop between waves. It did. That first version still lives in the repo, for anyone curious where this started.
●
Phase 2: Foundation (current)
That single file got rebuilt from scratch into a proper, organized codebase, tested and open source on GitHub. A steady stream of bug fixes and balance passes based on real playtesting, plus the tools (compendium, guide, stat transparency) needed to keep improving everything that comes after this.
Phase 3: Content Expansion
More items, enemies, and bosses. Deeper variety in how a run can play out.
Phase 4: Systems and Depth
Ideas on the table: meta-progression between runs, additional modes, more build variety. Nothing locked in yet.
★
Phase 5: Release Prep (the goal)
Final polish, everything a real release needs beyond just the game itself. This is the actual target I am working toward.
✨
Stretch Goal: Steam Release
Targeting Q4 2027, no later than early 2028, but this is not a promise. As a solo hobby project, this is where I would love to end up, not a date I am committing to.
