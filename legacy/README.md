# Legacy version

`original-single-file-version.html` is the pre-restructure version of the
game — the single HTML file this whole project was built from. It's kept
here for direct comparison while playtesting the restructured version:
open both side by side and confirm a run feels identical.

This file is NOT part of the build and isn't imported by anything in
`src/`. It's safe to delete once you're confident the restructured
version matches it.
